Cicada from HackTheBox involves attacking a domain controller with various misconfigurations which result in us gaining winRM access as a low privilege user. 

It turns out that this user has the powerful `SeBackupPrivilege` likely due to being part of the Backup Operators group which we can use to quickly grab the root flag.

After the initial nmap scan we find the DC is running a `SMB` service which allows `Null Authentication`. 

We fist listed the SMB shares with `smbclient -N -L //IP/` which revealed the interesting HR share.

Exploiting this we manage to find a file containing the `default password` for new users in the domain.

## Beyond Root

Since we have access to the full system we would be able to take copies of the `SAM, SECURITY and SYSTEM` registry hives, dump the contents on our kali machine using `impacket-secretsdump` and dump the NT hash of every user in the domain.

We could then use the domain Administrator hash in a `Pass the hash` attack to gain full control over the Domain.

## Thoughts

I found this to be quite an interesting box as I tried doing it just before I finished the pentester path on HTB and to land on a DC with no obvious way in was a bit strange at first but I manged to get through it and was very happy about it as some of the attacks like using rpcclient are slightly out of scope of the CPTS exam. Its interesting to look back at my original write up for this and see how much my skills and knowledge have improved and how I would likely approach the box differently if I was to do it now.
